#Budget Management 💸
EN: A lightweight, multi‑currency budget tracker with daily safe‑to‑spend guidance, category tracking, trends, and backups.
TR: Günlük harcama limiti, kategori takibi, trendler ve yedekleme ile çoklu para birimli sade bütçe takip uygulaması.
Features / Özellikler
EN
Multi‑currency budget setup
Daily safe‑to‑spend limit (hidden if end date is empty)
Expense logging with categories + notes
Category filters & search (toggle)
Weekly & monthly summary
Spending breakdown + trend charts
Detailed view (all transactions)
Bulk select / delete + undo
JSON backup export/import
Excel export (.xlsx)
Multi‑language UI (EN / TR / DE)
TR
Çoklu para birimli bütçe kurulumu
Günlük güvenli harcama limiti (bitiş tarihi yoksa gizlenir)
Kategorili + notlu harcama ekleme
Kategori filtreleri + arama (aç/kapa)
Haftalık & aylık özet
Harcama dağılımı + trend grafikleri
Detaylı görünüm (tüm harcamalar)
Toplu seçim/silme + geri al
JSON yedekleme (export/import)
Excel export (.xlsx)
Çok dilli arayüz (EN / TR / DE)
Tech / Teknoloji
HTML + CSS + Vanilla JS
Chart.js (CDN)
ExcelJS (CDN)
LocalStorage (no backend)
Run / Çalıştır
EN: Open index.html in your browser.
TR: index.html dosyasını tarayıcıda aç.
Notes / Notlar
EN: All data is stored locally in the browser.
TR: Tüm veriler tarayıcıda yerel olarak saklanır.
